# MINDSCAPE — 경험으로 배우는 심리학

**웹사이트:** https://gwonjae06-droid.github.io/mindscape/

인간관계·사회·집단·윤리·인지 영역의 심리학을 **핵심 개념 → 일상 사례 → 짧은 활동 → 이해도 확인** 순서로 공부하는 인터랙티브 학습관입니다.

## 학습 카테고리

| 카테고리 | 학습 주제 수 | 콘텐츠 |
| --- | ---: | --- |
| 인간관계 | 4 | 기본적 귀인 오류, 후광효과, 상호성과 자기개방, 근접성과 유사성 |
| 사회 | 2 | 방관자 효과, 사회 규범과 역할 |
| 집단 | 2 | 동조와 애쉬 효과, 집단사고 |
| 윤리 | 2 | 정의로운 세상 가설, 도덕적 이탈 |
| 인지 | 8 | 스트룹 효과, 작업기억, 확증편향, 프레이밍 효과, 인출 연습, 분산 학습, 가용성 휴리스틱, 기준점 효과 |

**총 18개 주제**입니다. 분야·검색·학습 상태 필터를 함께 사용할 수 있고, 카테고리별 학습 완료 수를 표시합니다.

## 2026-10-29: 선택에서 복습까지

- 상황별 추천 코스 3개: 관계의 오해 줄이기 / 내 판단 점검하기 / 배운 것을 오래 기억하기. 각 코스는 3개 주제를 순서대로 안내하고 완료 현황을 표시합니다.
- 각 주제에 약 5분의 예상 시간, 한 문장 개념 미리보기, 핵심 정리 바로 읽기를 제공합니다. 예상 시간은 읽기 속도에 따라 달라집니다.
- 4개 새 주제에 각각 9단계 이야기, 3개 선택과 후속 장면, 심리학 노트, 4지선다 확인 문제, 적용 질문과 출처를 추가했습니다.
- 전체 18개 주제에 '내 말로 설명해 보기'와 펼쳐 보는 한 문장 정리를 제공합니다.
- 별표 저장, 미학습/완료/저장 필터, 최근 읽은 주제 다시 열기. 주제에서 돌아와도 검색과 분야 조건이 유지됩니다.
- 브라우저 저장: 기존 `mindscape.lessons.completed.v1`을 유지하고, 저장 목록·최근 주제는 `mindscape.study.v1`에 기록합니다. 서버 전송은 없으며 저장이 차단되어도 방문 중 학습은 가능합니다. 최근 주제는 처음 장면부터 다시 열립니다.
- 정답을 선택해야 완료됩니다. 요약 열기나 이야기 읽기만으로 완료 처리하지 않습니다.
- 녹색 강조색, 넉넉한 본문 글자 크기, 모바일 카드, 키보드 포커스를 정리했습니다. 이야기 배경이 다른 영역을 덮던 위치 지정 문제도 수정했습니다.

### 파일과 테스트

`learning-content.js`는 새 학습 데이터를, `learning-ui.css`는 학습 화면 스타일을 관리합니다. 기존 이야기·실험 데이터와 빌드 없는 정적 구성을 유지합니다.

Node.js와 Playwright, Microsoft Edge를 설치한 환경에서:

```sh
npm install --no-save playwright
node tests/learning.cjs
```

다른 Playwright 브라우저 채널은 `BROWSER_CHANNEL`로 지정할 수 있습니다. `SCREENSHOT_DIR`을 지정하면 데스크톱 및 모바일 스크린샷을 저장합니다. 테스트는 로컬 서버를 자동으로 시작하고 종료하며, 18개 이야기·코스 순서·저장·필터·퀴즈·기록 유지·저장 차단·320/390px 화면 넘침을 확인합니다.

새 주제 참고: [기억과 학습](https://openstax.org/books/psychology-2e/pages/8-4-ways-to-enhance-memory), [문제 해결과 판단](https://openstax.org/books/psychology-2e/pages/7-3-problem-solving). 일상 이야기와 문항은 개념 이해를 위해 새로 작성한 가상 사례입니다.

아래는 기존 14개 주제의 구성과 이전 업데이트 기록입니다.

## 미니 체험

- 인간관계·사회·집단·윤리의 새 주제 10개: 일상 상황에서 여러 설명이나 대응 중 하나를 선택하고 심리학적 관점을 확인합니다.
- 기존 스트룹 효과: 일치/불일치 6문항의 색 선택.
- 기존 작업기억: 숫자 5개를 4초 동안 기억.
- 기존 확증편향: 증거 선택과 관점 확인.
- 기존 프레이밍 효과: 같은 비율을 다른 표현으로 비교.
- 모든 주제에는 별도의 객관식 이해도 문제가 있습니다.

**학습용 안내:** 짧은 상황 선택과 미니 테스트는 심리적 성격, 능력, 관계의 질, 윤리성을 진단하는 심리검사가 아닙니다. 설명은 개념 이해를 위한 예시이며, 실제 인간관계의 복잡한 사정과 차이를 일반화하지 않습니다.

## 프라이버시와 구현

- 정적 HTML/CSS/JavaScript. 별도의 설치 과정 없음.
- 학습 완료 여부만 현재 브라우저 localStorage에 저장, 기존 4개 주제의 완료 기록도 유지.
- 응답과 짧은 체험 결과는 서버로 업로드되지 않음.
- 모바일 레이아웃, 키보드 포커스, 응답 피드백의 접근성 고려.
- 사이트에서 포트폴리오로 돌아가는 링크 제공.

## 검증하기

1. 카테고리 **전체/인간관계/사회/집단/윤리/인지** 필터와 주제 검색을 확인합니다.
2. **인간관계 4, 사회 2, 집단 2, 윤리 2, 인지 4**개가 각각 표시되는지 확인합니다.
3. 각 카드에서 개념, 일상 사례, 체험 선택, 이해도 문제, 출처를 볼 수 있는지 확인합니다.
4. 미니 상황 문제를 골랐을 때 설명이 나타나고 다른 선택으로 다시 풀 수 있는지 확인합니다.
5. 객관식 정답을 고르면 학습 완료가 14개 중 1개로 집계되는지 확인합니다.
6. 기존 6문항 스트룹 체험과 숫자 기억 체험이 유지되는지 확인합니다.
7. 카테고리 필터 상태에서 검색 및 주제 이동/돌아가기를 확인합니다.

## 비주얼 노벨 학습 경험

아르카나 카드를 뽑아 들어간 **14개 모든 학습 주제**는 독자가 장면과 인물의 대화를 읽고 직접 선택하는 짧은 이야기 형식으로 구성됩니다.

- 장면 소개 → 등장인물의 대화 → 독자의 3가지 선택 → 선택별 후속 장면 → 심리학적 해설 2장면 → 짧은 정리 → 이해도 질문
- 선택별 전개는 교육용 가상 시나리오이며 **정답 여부나 인격을 평가하지 않습니다.**
- 이해도 확인 문제를 정답으로 풀면 기존 `mindscape.lessons.completed.v1` 키에 학습 완료 기록이 저장됩니다.
- 주의·작업기억·확증편향·프레이밍의 기존 미니 실험은 ‘짧은 인지 실험 해보기’ 접기 메뉴로 이동했습니다.
- 핵심 개념 원문, 일상 사례, 학술·교육 출처는 각 이야기 아래 ‘더 깊이 보기’ 및 ‘근거와 출처’ 메뉴에 유지했습니다.
- 비주얼 노벨 장면은 CSS 그래디언트·실루엣으로 표현합니다. 작은 화면과 동작 줄이기 설정을 지원합니다.

### 간단 검증 절차

1. 아르카나 세계에서 서로 다른 학습 카드 2~3개를 뽑아 장면을 진행합니다.
2. 선택지 3개를 각각 시험해 보고 후속 장면이 달라지는지 확인합니다.
3. 이후 심리학적 설명과 이해도 질문이 나타나는지 확인합니다.
4. 정답을 선택해 기록이 저장되고, 다른 카드로 넘어갔다 다시 복습할 수 있는지 확인합니다.
5. 인지 카테고리에서 기존 미니 실험이 접기 메뉴에 남아 있는지 확인합니다.
6. 모바일 화면 크기와 키보드 조작, 동작 줄이기 환경도 확인합니다.

## 2026 학습 자료실 개선

- UI: 강한 발광·회전 애니메이션과 어두운 카드 연출 대신 따뜻한 종이색, 단순한 목록, 높은 대비의 대화창을 사용합니다.
- 첫 화면에서 5개 카테고리와 14개 주제를 바로 둘러볼 수 있습니다.
- 모든 스토리의 종료 단계에 **심리학 노트**가 나타납니다: 핵심 정의, 작동 원리, 유사 개념과의 차이, 연구 근거, 실제 적용, 주의점.
- 심리학 노트는 \`psychology-notes.js\`의 14개 데이터 항목으로 관리됩니다. 출처는 주제마다 함께 표시합니다.
- 기존 14개 이야기, 42개 선택지, 이해도 문항, 4개의 미니 인지 체험, 브라우저 내 학습 완료 기록을 유지합니다.
- 새 심리학 노트의 자료로 OpenStax Psychology 2e, APA Dictionary of Psychology, NIST, PubMed 연구, 학술논문을 사용했습니다.
