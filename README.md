# MINDSCAPE · 마음을 경험하는 심리학

심리학 현상을 **직접 체험한 뒤 쉽게 이해하도록** 만든 인터랙티브 학습 웹사이트입니다.

## 첫 챕터 — 스트룹 효과

- 4문항 연습 + 24문항 본 실험 (일치·불일치·중립 조건 8문항씩)
- 글자색 선택: 마우스·터치 또는 키보드 1~4
- 정답률·정답 반응시간 중앙값·조건별 차이
- 세 조건을 바꿔보는 인터랙티브 해설
- 반응형, 움직임 줄이기, 설명만 보기
- 로그인·쿠키·외부 분석 및 서버 데이터 전송 없음

**안내:** 짧은 교육용 변형 실험이며 성격·지능·집중력·정신건강 검사나 진단이 아닙니다. 화면/입력 지연, 색각, 조명, 학습·순서 효과가 결과에 영향을 줄 수 있습니다.

## 실행

브라우저에서 `index.html`을 열면 됩니다. 현재 버전은 **HTML 한 파일**에 스타일과 실행 코드를 함께 담았으므로 빌드·패키지 설치가 필요 없습니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 설정하세요.

배포 설정이 완료되면 예상 주소: https://gwonjae06-droid.github.io/mindscape/
